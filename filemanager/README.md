# FileManager

与 FileSync、FileIndex 并列的 Go 模块，承载共用文件后台。三个仓库通过相对路径 replace 联调，需要一起检出。

## 已接入

- `catalog`：独立的多根索引所有者，管理每根快照、日志回放、扫描串行化和查重结果；FileIndex 的搜索、统计、查重及扫描已切入，不依赖 SQLite 文件表。
- `index`：树形二进制快照、增量层、检索、操作日志。FileSync 使用 `/v1/index`，索引数据和分页结果留在后台；结果固定版本，有 10 分钟租约及数量限制，过期明确报错。
- `fs`：基于 `os.Root` 的受限根复制移动、显式文件替换/目录合并策略、独占临时文件、取消及源清理收据。目标父目录使用固定句柄；移动复制失败时保留源，新增子项不会被递归清除。
- `engine`、`remoteclient`、`archive`：共用备份计划执行、远端协议、归档读取器及原有测试。客户端和服务端直接依赖同一份 archive，不再复制源码。
- `api`、`client`、`service`：HTTP(S)/Unix socket 的浏览、属性、基础写操作、有界文件读取、目录递归统计、复制移动任务、可信本机索引、备份及跨端传输。
- `localprocess`：前台托管的本机后台，私有 socket、就绪握手、拥有者管道关闭后取消并等待退出。
- FileIndex：在原认证层内运行持久化共用服务；基础写入和复制移动遵守根目录只读/排除规则、所有者及权限策略，并直接更新共用树索引。根配置或挂载身份变化时取消并等待旧服务，再重新打开根句柄。

FileSync 的备份计划扫描/执行、上传、下载、续传及服务器间中转数据流已在后台运行。前台负责呈现、确认、批次与部分兼容编排。

## 协议和持久化

实际能力查询 `/v1/info`。受限远端只接收根 ID 与相对路径，不启用可信本机的绝对路径索引、备份及传输协调接口。Unix 非 UTF-8 路径通过字节字段传输。

基础修改和传输意图先追加至独立的 `mutations.log`，完成后追加结果；日志带 CRC、序号、fsync 和进程锁。损坏时拒绝写入，不静默删除证据。重启不重新执行未完成操作。

`POST /v1/transfers` 接收稳定的 128 位十六进制任务 ID。同 ID 同请求去重，不同请求冲突；`GET /v1/tasks/{id}` 查进度/结果，`POST /v1/tasks/{id}/cancel` 请求取消后应等待终态。未完成任务重启后标记 interrupted。当前保留最多 10000 项，尚未自动归档。

`/v1/backup` 与 `/v1/remote` 当前是 NDJSON 请求流，已有意图/结果日志，但尚未统一为可重连查询的持久化任务。请求断开不能据此判断文件未修改，也不能盲目重复执行。备份凭据只存在于内存计划中，跨端日志去掉 token。

后台修改会异步回放至已打开的本机索引，加载快照时也从后台日志补充回放。前台原操作日志桥接暂时保留。完整扫描与增量清理在后台取得写入锁，并核对完整扫描后的日志序号；若快照后有新操作则保留增量，不能因前台检查点成功而删除后台证据。索引生命周期与自动压缩仍需继续收敛至后台。

## 构建

需要 Go 1.27.3：

```sh
go test ./...
go test -race ./...
go build -o build/filemanager ./cmd/filemanager
../filesync/scripts/build-desktop.sh
```

独立命令提供 `--socket`、`--root`；写入加 `--journal`，桌面托管加 `--owner-stdin`。socket 放在自己拥有的 0700 目录，不覆盖现有 socket。日志须放持久化数据目录。远端监听与认证由 FileIndex 提供。

## 尚未完成的验收项

此版本仍是迁移中，不能按“FileSync 纯前台、全部统一后台”验收：

1. FileIndex 核心已切换为 catalog/tree，使用新 metadata.db，不迁移旧文件索引；其余旧文件业务接口还需继续收敛至统一服务和任务协议。
2. 索引配置、快照检查点及旧日志桥接仍由前台编排；外部文件变化监听、补扫、统一压缩未完成。
3. 基础修改、备份、跨端传输仍需统一任务历史、幂等、取消确认、重连查询及事件游标；现有复制移动任务尚无日志归档。
4. 用户级后台单实例复用、根/挂载发现和统一配置迁移未完成。
5. 缩略图文件读取和目录递归统计已转入后台；前台仍有基础属性、本机路径探测及系统集成逻辑；远端受管回收站、预览等旧接口尚未全部迁入共用服务。
6. 撤销、受限重试、高级元数据及 Windows IPC/运行验收未完成。Windows 交叉编译不代表功能可用。

配置、认证、回收站、未完成上传和操作证据必须保留；只有搜索索引允许重建。取消或失败允许保留已完成的部分结果，不承诺全局回滚。

### 文件名模式搜索

默认搜索同时支持关键词和通配符，不区分大小写。无通配符的条件按包含匹配；含 `*`、`?` 的条件匹配完整文件名，`*` 表示零个或多个字符，`?` 表示一个 Unicode 字符。空格分隔的条件必须全部满足，例如 `年度 *.pdf`。`\*`、`\?` 和 `\\` 用于匹配字面符号，方括号等其他字符没有特殊含义。

开启“正则”后，整个输入作为 Go 正则表达式处理，不按空格分词；默认忽略大小写、匹配名称中的任意部分，使用 `^` 和 `$` 限定首尾，不支持环视和反向引用。输入最多 4096 字节，语法错误会提示。当前仅匹配文件名，不匹配完整路径，无需重建索引。NAS HTTP 搜索通过 `regex=1` 启用正则；本地后台使用 `index.Query.Regex`。

本机后台默认采用 512 MiB Go 软内存预算，可用 `GOMEMLIMIT` 覆盖；只读索引映射页不计入该预算。索引调用方应在结果弃用时调用 `Results.Close()` 释放后台查询租约；后台每 30 秒清理超过 10 分钟未访问的查询。启用本机索引的 `/v1/info` 返回 `memory`，包含堆分配、已释放内存、预算、索引会话和保留查询数量。

### MyGo 设备只读共享

`filemanager --share /path/to/sharing.json --owner-stdin` 启动独立的只读共享后台。由 MyGo 的“设置 → 设备共享”生成配置、选择根目录和启动/停止，默认监听 `:17891`；未开启共享时不监听网络。配置含访问码和自签名证书私钥，按 0600 保存。分享的 `mygo://` 邀请同时携带地址、访问码和证书指纹；接收端固定校验证书，禁用重定向，凭据仅通过 HTTPS 发送。

共享后台打开单独的 `os.Root` 受限句柄，不启用写入、可信本机索引或传输协调接口，不挂载本机的 `/v1` 路由。面向现有桌面浏览器提供只读的 roots/list/props/download/export 适配，文件支持 HTTP Range 和 ETag；目录以带完成标记的 tar 流传输。配置目录及其符号链接别名不可读取；导出遇到符号链接、特殊文件、过深目录或文件变化会失败，不把部分归档当成功。

当前只支持手动邀请连接和读取。上传、远程删除/移动、远程索引搜索、在线归档浏览及自动发现设备尚未开放。登录会话保留在共享进程内，停止后失效，重新开启后需在接收端重新粘贴邀请连接；重置访问码可使旧邀请失效。桌面关闭所有者管道时共享停止，不作为系统常驻服务。没有修改操作系统挂载或防火墙规则。
