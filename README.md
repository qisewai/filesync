# FileSync · fileindex 客户端

浏览、搜索和管理 NAS 上的 [fileindex](../fileindex) 文件，也可以把本机目录备份过去，支持 Linux 和 Windows。界面使用 [MyGo](https://github.com/egoist/mygo) 的 Native UI 编写（纯 Go，不需要 cgo，也不需要 WebView）。

原生文件管理包括：

- 文件管理器式布局：左侧是位置（本机、各台服务器、备份任务），顶部工具栏有后退、前进、上级和横贯整条的搜索框，下面一行是当前路径（或页面标题、管理页的标签），底部状态栏显示项数、选中项、传输和本机索引状态。后退/前进也可以用 Alt+←/→ 或鼠标侧键，上级用 Alt+↑。
- 左侧按服务器、索引目录和子目录展示目录树，展开时才读取子目录；默认读取索引，开启“实时”后读取硬盘。服务器下是目录树、回收站和“管理”；管理页的工具栏上有目录管理、查重、空间统计三个标签（服务器的右键菜单也能进入）。目录管理选中一个索引目录后，上方显示它的操作（更新索引、打开、编辑、移除，扫描记录和完整校验为图标按钮）。
- 本机、NAS 和回收站用同一套文件视图：列表或网格（本机图片和 NAS 支持的格式显示缩略图），支持多选；缩略图最多缓存 256 张，切换目录时取消旧请求。
- 文件上方的命令栏平时显示新建文件夹、上传（本机页的备份和在文件管理器中显示在右键菜单里）；选中文件后变成选择操作条，显示已选数量和大小，以及下载、复制到、移动到、重命名、删除等（NAS），窄窗口下放不下的操作收进条末的菜单。Esc 取消选择，F2 重命名，F5 刷新，Delete/Shift+Delete 删除。较少用的选项（实时读取硬盘、显示隐藏文件、刷新、本机索引）在 ⋯ 菜单里。
- 搜索：所有搜索都在同一个搜索页。任何页面在工具栏的搜索框输入（或按 Ctrl+F、Ctrl+K）就打开搜索页，边输入边出结果；后退回到原来的页面。
  - 范围默认跟着所在的位置：本机页是“本机”，NAS 页是那台服务器，其他页面是“全部位置”；搜索框左侧的标签可以改，也可以选“此文件夹”。
  - 搜索页上方的范围标签显示各处找到多少项，点击在页内切换：“全部位置”把本机和所有已登录服务器的前 200 项合在一张表里并标明来源；选一个位置（或“此文件夹”）显示它的全部结果，滚动到底自动加载下一页，表头排序作用于全部结果。
  - 可按类型（文件夹、图片、视频、文档、压缩包、磁盘镜像等）、扩展名、修改时间、大小筛选，本机和 NAS 一致。
  - 结果可以直接操作：同一台服务器、同一个索引目录的结果可以下载、复制到、移动到、重命名、删除（Delete、Shift+Delete、F2）；本机结果可以创建备份任务、在文件管理器中显示；任何结果都能打开或打开所在位置。来自不同位置的结果请分别操作。
  - 本机还没有建立索引时，搜索页提示并可直接建立；侧边栏“搜索”和搜索页的空白状态列出最近搜索（保存最近 8 条）。
- 文件、文件夹上传和拖拽上传；同名文件替换前询问，文件夹合并。一次选择的上传项若有重名，会提示分别上传。
- 文件直接下载；目录及批量选择通过一条 tar 流下载并解包到本机。同名的批量下载项会编号，本机已有同名项则替换前询问。保留文件修改时间、权限和符号链接；不完整的文件不会替换本机原文件。
- 新建文件夹、重命名、移入回收站、在同一服务器的索引目录之间复制或移动。同名的复制、移动目标由服务端自动编号。
- 状态栏的传输指示，点开是传输任务列表；复制、移动进度通过实时事件更新，并定期核对任务列表以恢复漏掉的事件。正在传输时退出会先询问并等待本机传输清理。
- 侧边栏“本机”列出主目录、文件系统（Windows 下为各个盘）和已挂载的网络共享、移动硬盘，可逐级展开浏览本机文件。选中文件夹或文件后右键选择“创建备份任务…”，在弹窗中设置目标和模式；在空白处右键选择“备份当前文件夹…”。“在文件管理器中显示”也在右键菜单里。
- “备份任务”每个任务一张卡片，显示备份内容、目标、模式和上次运行结果。“立即备份”比较后直接备份，进度和结果显示在卡片里（“详情”查看完整结果和出错文件）；只有会删除 NAS 上文件时（完全一致模式）才先打开预览请你确认，比较出错时也会打开预览。卡片的 ⋯ 菜单里有“预览并备份…”“详情与运行记录”“编辑…”“删除任务…”。系统托盘菜单中的备份任务也是立即备份。
- 新建/编辑任务的对话框：模式用分段按钮切换，只显示当前模式的说明；排除规则收在“高级选项”里。保留原来的增量、完全一致和归档功能。左下角“设置”打开设置页：服务器（状态、登录、管理、编辑、网页管理）、本机索引（状态、索引目录、更新、编辑范围）和常规（关闭窗口时最小化到托盘、设置文件夹、清除最近搜索）。

复制沿用 fileindex 的现有策略：目录里的符号链接会跳过，任务完成时会显示服务器返回的跳过提示。上传和目录下载会保留符号链接。

第二阶段的预览和打开已实现：

- 双击图片或文本会打开原生预览，支持上一项、下一项；文本只读且可选择复制。图片支持适合窗口、原始大小，滚轮以指针为中心缩放（双击切换原始大小），放大后拖动平移，松手带惯性滑行、拖过边缘会回弹；未放大时左右甩动切换上一张、下一张。缩放和平移是同一个弹簧动画。
- 图片支持 JPEG、PNG、GIF（首帧）、WebP 和 BMP；JPEG 根据 EXIF 自动转正。预览限制 32 MiB 和 1600 万像素，超出时可用系统程序打开。
- 文本支持 UTF-8、UTF-16 和 BOM，常见源码、配置、日志、字幕也可预览；最多读取前 256 KiB，超出时提示打开完整内容。HTML、SVG 等按文本显示。
- 音视频通过仅监听 `127.0.0.1` 的本机代理播放，支持 HTTP Range 拖动。客户端生成 `.m3u` 播放列表交给系统默认播放器，因此需要将 `.m3u` 关联到 VLC、mpv 等支持 HTTP 播放的程序；右键“下载后打开”可供不支持网络播放的程序使用。播放期间需要保持 FileSync 运行。
- PDF、Office 和其他文件通过本机代理下载到缓存，再用系统默认程序打开；需要本机安装对应的阅读器或 Office 软件。缓存按服务器、路径、文件大小和修改时间区分，未完整下载的内容不会替换已有缓存。预览工具栏和右键菜单也可选择“系统程序打开”。系统程序保存的修改留在本机缓存，不会自动上传，重新打开同一 NAS 版本会保留这些修改；要更新 NAS 文件请手动上传。
- 每个服务器下面都有原生“回收站”页面，支持筛选、多选恢复和确认后永久删除，自动响应实时事件。恢复同名文件时由服务端自动编号；只读目录中的项不能恢复或删除。永久删除进度进入任务面板。

代理 URL 使用独立随机凭据，不包含 NAS 登录会话；退出登录、更改服务器或关闭客户端会撤销链接并停止对应的流。

第三阶段的原生管理包括：

- 每个服务器下的“目录管理”支持添加索引目录、浏览服务器目录、编辑名称、只读状态和排除规则，以及按小时、每天或每周自动更新。时间按服务器时区执行。
- 可以启动增量更新、确认后完整校验、取消扫描，并查看最近 20 次扫描记录。扫描进度进入全局任务面板，通过实时事件更新；定期查询扫描记录以恢复遗漏的事件。
- 移除索引前会确认，不删除硬盘原文件，但会移除该目录的扫描和回收站记录。已有备份任务保留，需要自行重新设置被移除的目标目录。
- “查重”支持选择一个目录或全部目录、设置最小大小、分页查看内容相同的文件。本页可按修改时间保留最早或最新的副本，每组至少保留一份；只读副本不可删除。删除勾选的副本前会确认，文件进入回收站。
- “空间统计”显示总大小、文件数、文件夹数、类型、扩展名、修改年份和最大的 50 个文件。文件类型是环形图，指向扇区或图例时两边一起高亮；修改年份是带刻度的柱状图，指针或左右方向键逐年查看大小和文件数。文件夹占用可逐级展开，大文件和重复文件都可以预览或定位到所在目录。
- 统计读取索引；扫描和查重会读取 NAS 硬盘。文件变化后自动刷新统计和查重结果。以上功能复用现有服务端接口，不需要额外部署。

## 功能

- **多个服务器**：在“设置 → 服务器列表…”中添加、编辑、删除 fileindex 服务器（名称 + 地址），登录或退出登录。只保存登录会话，不保存密码；会话过期时预览会提示重新登录。还有任务在用的服务器不能删除。
- **选择备份到的目录**：选择服务器 → 登录 → 选择 fileindex 的索引目录 → 逐级进入子目录，也可以新建文件夹。
- **三种模式**
  - 增量备份：上传新增和修改过的文件，NAS 上多出来的文件保留不动。
  - 完全一致：在增量备份的基础上，把本机没有的文件移到 fileindex 的回收站（默认保留 30 天）。
  - tar 归档：把整个源目录打包成一个归档文件保存到 NAS，每次生成一个新文件（如 `xiaomai-20261010-160500.tar.gz`），不与 NAS 上已有的内容比较。可选 gzip（默认，多核并行压缩）、不压缩或 zstd。请求末尾附带字节数，NAS 核对完整后才以正式文件名保存。
- **同名文件夹**：备份一个文件夹时，默认在目标中创建与它同名的文件夹（归档模式下是归档里的顶层文件夹）；取消勾选则只备份文件夹里的内容。
- **备份选中的多项**：同时选中多个文件或文件夹（或单个文件）时，它们直接放进目标目录；同一目录下没选中的项不会上传，完全一致模式也不会删除 NAS 上它们以外的文件。
- **先预览再执行**：先列出要新增、更新、删除、跳过的文件，确认后再开始。
- **排除规则**：glob 语法，例如 `*.tmp`、`node_modules`、`cache/`、`/build/out`。

## 本机文件检索

在“本机”页面底部状态栏的“索引”菜单中选择“索引范围…”设置本地目录和排除规则，再选择“更新索引”（还没有索引时，搜索页也有“建立索引”按钮）。默认范围是主目录，默认排除 `.cache/`；其他本地磁盘可以添加绝对路径。扫描在后台运行，可取消；首次扫描会逐步发布结果，扫描期间也能搜索。

- 按文件名搜索，空格分隔的词须同时匹配，忽略大小写；结果在统一的搜索页里（见上文），本机结果来自这份索引。
- 选中本机的搜索结果可创建备份任务。来自不同目录的结果按来源目录分别打开设置窗口；保存后继续设置下一个，取消会结束剩余设置。
- 索引只读取文件名和元数据，不读取文件内容。扫描去除重叠范围，跳过识别出的网络挂载、系统虚拟目录和特殊文件，符号链接不会递归扫描。

本机索引完全由手动扫描更新，没有文件监听、定时扫描或启动扫描。“刷新”重新查询当前内存索引；文件新增、修改、移动或删除后，需要在“索引”菜单中选择“更新索引”。不可读目录保留已有记录并显示提示；取消重扫时，尚未完成的索引范围保留旧记录；取消首次扫描保留已建立的部分。

第二阶段已实现快照持久化和手动增量更新：

- 启动只在后台加载已有快照，不扫描索引目录。加载后可以直接搜索离线目录中的旧记录；打开已移动或删除的文件会提示手动更新。
- “更新索引”核对目录修改时间。未变化的小目录复用文件名列表，仍逐项核对已有文件的大小、修改时间、类型和隐藏属性；发生变化的目录重新枚举，大目录分批读取以限制临时内存。“全部重建”重新枚举全部目录。
- 目录时间比对不能识别其他程序强行恢复目录时间后新增的未知文件，也不能提供整个文件系统在同一时刻的快照；遇到这类情况请使用“全部重建”。更新在内存中重建不可变结果版本，以保持分页一致。
- 完成手动扫描后自动保存带格式版本、索引范围校验和 SHA-256 校验的二进制快照，通过临时文件、同步写入和原子替换保存。损坏、旧格式或配置不匹配的快照不会被发布，界面会提示手动重建。保存失败时当前索引仍可搜索。
- 取消扫描或保存会保留磁盘上的已有快照；本次尚未保存的数据只在当前进程中可用。不可读范围保留旧记录，相关提示也随快照保存，重启后仍会显示。改变索引范围或排除规则后旧缓存失效，需要手动重新建立。

快照默认位于 `~/.cache/filesync/local-index.bin`（遵循 `XDG_CACHE_HOME`），Windows 位于 `%LocalAppData%\filesync\local-index.bin`；索引范围和排除规则继续保存在设置文件中。状态栏显示加载、核对目录、保存进度和上次更新时间。扫描期间旧、新索引可能同时存在，搜索结果也保留其所属版本，实际进程峰值内存会高于索引本身。百万项模拟数据的测量命令：

```sh
go test ./localindex -run '^$' -bench BenchmarkMillion -benchmem
```

## 传输方式

不经过 SMB，而是直接和 fileindex 通信：

- NAS 在本地一次性列出目标目录（2 万个文件约 0.1 秒）；
- 要传的目录、文件和符号链接作为**一条标准 tar 流**，在**一个连接、一个请求**中连续发送，磁盘可以顺序写入，小文件也不用逐个往返；
- NAS 边收边解开成普通文件，每写好一个就回一条确认：进度显示的是 NAS 上真正写好的文件，连接中断时也能准确知道哪些已经写好，下次备份会接着传；
- 保留修改时间、可执行权限和**符号链接**；文件属主沿用 fileindex 的设置（Unraid 上为 nobody:users，与 SMB 写入的一致）；
- 文件写好后，服务端异步更新索引，并通过实时事件通知客户端刷新。

需要 NAS 上的 fileindex 包含 `/api/backup/manifest`、`/api/backup/tar` 和 `/api/backup/file` 接口（`/api/backup/file` 需要支持 `X-Backup-Size` 结尾标记）。

目录下载还需要 `GET /api/backup/export?root=索引目录ID&path=相对路径`（`path` 可重复）；返回标准 tar 流，`X-Total-Size` 是索引中的估计字节数，`X-Export-Complete: 1` HTTP trailer 表示导出完整结束。客户端也会检查 tar 的结束块。

## 安全措施

- 完全一致模式下，如果源目录为空而 NAS 上有文件，拒绝执行（防止源目录未挂载时清空备份）。
- 要删除 NAS 上一半以上的文件时，会再次弹窗确认。
- 删除的文件进入 fileindex 回收站，可以恢复；含有被排除文件的目录会保留。
- NAS 上每个文件先写入临时文件，完整后再改名，不会留下写了一半的文件；传输中被修改而读不完整的文件会被丢弃，下次重传。
- NAS 拒绝写到索引目录之外，包括经由符号链接。
- NAS 上无法读取的目录，其中的内容不会被删除。
- 设备、管道等特殊文件会被跳过。

## 开发

需要 Go 1.27.1 或更高版本。Linux 上运行还需要 GTK 3。

```sh
go run .                 # 运行
go test ./...            # 测试（界面测试不需要窗口，用 fileindex/fitest 模拟服务器）
go tool mygo dev         # 开发模式，修改代码后自动重新加载
go tool mygo build       # 打包
GOOS=windows go build -o filesync.exe .   # 在 Linux 上交叉编译 Windows 版本
```

对真实的 fileindex 测速：

```sh
FILESYNC_E2E_ADDR=192.168.0.235:8090 FILESYNC_E2E_TOKEN=会话 FILESYNC_E2E_SRC=本机目录 go test -run E2E -v ./fileindex
```

设置和日志保存在 `~/.config/filesync/`（Windows 上是 `%AppData%\filesync\`），设置文件只有本人可读。
