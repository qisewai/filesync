# FileSync · fileindex 客户端

浏览、搜索和管理 NAS 上的 [fileindex](../fileindex) 文件，也可以把本机目录备份过去，支持 Linux 和 Windows。界面使用 [MyGo](https://github.com/egoist/mygo) 的 Native UI 编写（纯 Go，不需要 cgo，也不需要 WebView）。

原生文件管理包括：

- 三栏布局：左侧是侧边栏，中间是文件页，右侧是详情面板。窗口没有系统标题栏，最上面一行代替标题栏（空白处拖动窗口、双击最大化）：侧边栏顶部是应用名和收起侧边栏的按钮，文件页上方是标签页，详情面板顶部是收起详情的按钮；最小化、最大化、关闭按钮在最右端（Linux 上窗口为无边框，由 FileSync 绘制这三个按钮，窗口边缘仍可拖动改变大小：KWin 等 Wayland 合成器对只隐藏标题栏的窗口仍会加上自己的标题栏；Windows 上为系统自带按钮）。桌面环境上显示不正常时，可在“设置 → 常规”打开“使用系统标题栏”，重新启动后恢复系统标题栏。侧边栏依次是搜索、收藏、本机、各台服务器（每台服务器直接作为一组，组名是服务器名称，下面是它的索引目录、回收站和管理）和备份任务，选中项为浅灰底；传输记录在底部状态栏右侧。侧边栏底部是过滤框（按名称查找收藏、本机位置、索引目录和已展开过的文件夹，点击前往，右键可在新标签页中打开）、设置和添加服务器。标签页下面一行依次是后退、前进、上级、当前路径（或页面标题、管理页的标签）和搜索框，底部状态栏显示项数、选中项、传输和本机索引状态。后退/前进也可以用 Alt+←/→ 或鼠标侧键，上级用 Alt+↑；Ctrl+B 收起/显示侧边栏。
- 多标签页：每个标签页有自己的位置和前进后退历史，切换标签时保留各自的选中项和滚动位置，再次显示时重新读取当时没读完或已变化的内容。Ctrl+T 在当前位置新开标签页（或点标签栏的 ＋），Ctrl+W 关闭，Ctrl+Tab / Ctrl+Shift+Tab 切换，Ctrl+1…8 跳到对应标签、Ctrl+9 跳到最后一个。文件夹（文件列表、侧边栏目录树、收藏、过滤结果、搜索结果）的右键菜单有“在新标签页中打开”；标签的右键菜单可复制、左右移动、关闭其他或右侧的标签页。最多 12 个标签页，至少保留一个；退出后不保存标签页。
- 详情面板：显示选中项的缩略图（图片）或图标、名称和类型，以及属性（位置、服务器路径、大小、时间、权限、所有者等，NAS 文件夹另有索引中的文件数和总大小）；没有选中时显示当前文件夹，多选时汇总数量和大小。本机文件夹的总大小和文件数点“大小”旁的统计按钮后才计算，在后台进行：在本机索引范围内的直接取自索引（标明索引更新时间），不在范围内的遍历硬盘、边算边显示。Ctrl+I 或右上角按钮收起/显示，宽度可拖动并会保存；窗口太窄（文件页不足 640 像素）时自动隐藏，变宽后恢复。
- 收藏：本机和服务器上的文件夹都可以收藏，在文件夹的右键菜单（侧边栏目录树或文件列表）选“添加到收藏”，或点路径栏右侧的 ☆。收藏可以重命名、上移下移、移除；文件夹不存在、服务器未登录或无法连接时显示为灰色。备份目标、解压等选择目录的对话框顶部也列出收藏：服务器上的收藏直接打开到那里，本机的收藏（下载、解压到本机时）直接作为目标。收藏保存在设置文件中，删除服务器时一并移除它的收藏。
- “本机”下除了主目录、文件系统和挂载的磁盘，还列出桌面、文档、下载、图片、音乐、视频（Linux 按 `user-dirs.dirs`，Windows 为用户目录下的同名文件夹）。
- 路径栏：每一级都可以点击跳转，后面的 › 箭头列出该文件夹里的子文件夹，可直接跳到同级的其他文件夹。点击路径栏空白处或按 Ctrl+L 可编辑路径，整行都可以输入、复制和粘贴：本机写完整路径（`/home/me/文档`、`~/文档`、`D:\文档`），服务器写“服务器名/索引目录/文件夹”。每一级边输入边提示：第一级是各台服务器和本机的位置（选中本机位置时填入它的完整路径），服务器名后是它的索引目录，再往后是子文件夹；↑↓ 选择，Enter、Tab 或点击补全并接着列出下一级，没有选中提示时 Enter 前往。服务器名、索引目录写错或文件夹不存在时会直接提示；输入文件路径会打开它所在的文件夹并选中它。Esc 先关闭提示，再按一次取消编辑。服务器名称因此不能包含“/”。
- 左侧按服务器、索引目录和子目录展示目录树，展开时才读取子目录；默认读取索引，开启“实时”后读取硬盘。服务器下是目录树、回收站和“管理”；管理页的工具栏上有目录管理、查重、空间统计三个标签（服务器的右键菜单也能进入）。目录管理选中一个索引目录后，上方显示它的操作（更新索引、打开、编辑、移除，扫描记录和完整校验为图标按钮）。
- 本机、NAS 和回收站用同一套文件视图：列表或网格（本机图片和 NAS 支持的格式显示缩略图），支持多选；缩略图最多缓存 256 张，切换目录时取消旧请求。
- 和系统文件管理器一样，文件列表上方没有操作条：选中项的数量和大小显示在状态栏，操作都在右键菜单和快捷键里。文件上的右键菜单有打开、在新标签页中打开、剪切、复制、粘贴到此文件夹（选中一个文件夹时）、下载到…、压缩到…、重命名（F2）、删除（Delete，移入回收站）、彻底删除（Shift+Delete）、添加到收藏、属性；空白处的右键菜单（以及工具栏右端的 ⋯）有粘贴、新建文件夹（Ctrl+Shift+N）、上传文件/文件夹（服务器）、显示隐藏文件（本机）、刷新（F5）、文件夹属性。视图切换（列表/网格）在工具栏右端。Esc 取消选择。
- 搜索：所有搜索都在同一个搜索页，也是启动后的第一个页面：没有搜索时像搜索引擎首页，中间是大的搜索框，下面可选搜索范围（全部位置、本机、各服务器）、点最近搜索，还会提示没有服务器或本机还没建索引；开始输入后搜索框移到页面顶部，下面是结果，清除搜索框回到首页样式。任何页面在工具栏的搜索框输入（或按 Ctrl+F、Ctrl+K）就打开搜索页，边输入边出结果；后退回到原来的页面。
  - 范围默认跟着所在的位置：本机页是“本机”，NAS 页是那台服务器，其他页面是“全部位置”；搜索框左侧的标签可以改，也可以选“此文件夹”。
  - 搜索页上方的范围标签显示各处找到多少项，点击在页内切换：“全部位置”把本机和所有已登录服务器的前 200 项合在一张表里并标明来源；选一个位置（或“此文件夹”）显示它的全部结果，滚动到底自动加载下一页，表头排序作用于全部结果。
  - 可按类型（文件夹、图片、视频、文档、压缩包、磁盘镜像等）、扩展名、修改时间、大小筛选，本机和 NAS 一致。
  - 结果可以直接操作：同一台服务器、同一个索引目录的结果可以下载、复制到、移动到、重命名、删除（Delete、Shift+Delete、F2）；本机结果可以创建备份任务、在文件管理器中显示；任何结果都能打开或打开所在位置。来自不同位置的结果请分别操作。
  - 本机还没有建立索引时，搜索页提示并可直接建立；侧边栏“搜索”和搜索页的空白状态列出最近搜索（保存最近 8 条）。
- 属性：NAS 文件（文件列表、侧边栏目录树、搜索结果的右键菜单）显示类型、位置、服务器路径、大小、修改/访问/状态更改时间、权限和所有者；文件夹另显示总大小、包含的文件数和文件夹数（读取服务器的内存索引，标明索引更新时间；未建索引或文件夹还没进入索引时提示），以及直接包含的项数。需要新版 fileindex 的 `/api/roots/{id}/props` 接口，旧服务端只显示基本信息。当前文件夹的属性在文件列表空白处的右键菜单和右上角 ⋯ 菜单的“文件夹属性”里。本机文件和文件夹（文件列表、侧边栏、搜索结果）也有“属性”，文件夹的总大小和文件数实时统计，不跟随符号链接，关闭对话框即停止。
- 文件、文件夹上传和拖拽上传；同名文件替换前询问，文件夹合并。一次选择的上传项若有重名，会提示分别上传。
- 文件直接下载；普通 NAS 单文件下载支持断点续传，断网、取消或退出后保留已下载的数据，在“传输记录”点击“继续下载”；客户端重启后也可继续，使用当前登录会话。续传核对服务器文件版本和响应范围，源文件变化时从头下载，完整后才替换本机文件。需要服务端下载接口提供强 ETag（本版 fileindex 已支持）；旧服务端仍可下载，重试时从头开始。移动到本机、压缩包成员和目录/批量下载暂不支持续传。删除或清除任务记录会清理未完成数据，保留已下载完成的文件。
- 目录及批量选择通过一条 tar 流下载并解包到本机。同名的批量下载项会编号，本机已有同名项则替换前询问。保留文件修改时间、权限和符号链接；不完整的文件不会替换本机原文件。
- 复制粘贴打通本机和所有服务器：在任意位置选中文件按 Ctrl+C 复制或 Ctrl+X 剪切，到另一个位置（本机文件夹、同一或其他服务器的文件夹，也可以在另一个标签页里）按 Ctrl+V 粘贴，或在文件夹、侧边栏目录树、收藏的右键菜单选“粘贴到此文件夹”。状态栏显示剪贴板里的内容，可点 × 清空；剪切的项在列表中显示为半透明，粘贴后剪贴板清空，复制的可以反复粘贴。粘贴按来源和目标自动选择方式：
  - 同一服务器内：作为服务端任务复制或移动，同名的由服务端自动编号（在原文件夹里粘贴即得到副本）；不能把文件夹移到它自己里面。
  - 不同服务器之间：源服务器导出的 tar 流经本机直接转给目标服务器（不落本机磁盘，速度取决于本机网络，期间需保持 FileSync 运行）；剪切时在目标完整写好后才把源文件移入源服务器的回收站，没完整复制的项保留在源服务器上。
  - 服务器 → 本机：下载；剪切时全部完整下载后才把服务器上的文件移入回收站，有任何一项没下载好则全部保留。
  - 本机 → 服务器：上传；剪切时完整上传后才把本机文件移入系统回收站（Linux 为 freedesktop 回收站，其他磁盘上用该磁盘的 `.Trash-用户号`；Windows 为回收站），没完整上传或不能移入回收站的保留在本机。
  - 本机文件夹之间：直接复制或移动（同一磁盘上移动为重命名，跨磁盘为复制后删除源），保留修改时间、权限和符号链接，进度显示在传输记录里；在原文件夹里粘贴复制得到“名称 (2)”这样的副本。
  - 压缩包内的文件只能复制，粘贴时解压到目标。
  - 除同一服务器内外，目标中已有同名项时先询问，确认后文件替换、文件夹合并。
- 和系统文件管理器互通：在 FileSync 里复制或剪切本机文件，会同时放到系统剪贴板（`text/uri-list`，并带 KDE / GNOME 的剪切标记），可以在 Dolphin、Nautilus 等里粘贴；在它们里面复制或剪切的文件，可以在 FileSync 的本机或服务器文件夹里粘贴（剪切的粘贴后从原处移走）。复制服务器上的文件时，系统剪贴板里放的是文件名文本。
- 本机文件也可以新建文件夹（Ctrl+Shift+N）、重命名（F2）、删除到系统回收站（Delete）或彻底删除（Shift+Delete）。
- 状态栏的传输入口始终可用；启动时从配置目录的 `transfers.json` 恢复历史（Linux：`~/.config/filesync/transfers.json`；Windows：`%AppData%\filesync\transfers.json`）。保存类型、开始/结束时间、结果、错误、传输量和下载/缓存位置；下载完成后可重新打开文件或所在目录，缓存文件再次打开也会新增记录。历史在后台通过临时文件保存并原子替换，删除或清除记录也同步保存，退出时等待最后一次写入。上次退出时未结束的任务标记为“上次未完成”，不会自动继续；旧版未保存的记录无法还原。类型使用图标表示，悬停查看说明。任务行提供打开下载或缓存目录、取消和删除记录的图标按钮；进行中的任务须先取消，删除记录会保留下载文件。复制、移动进度通过实时事件更新，并定期核对任务列表以恢复漏掉的事件。正在传输时退出会先询问并等待本机传输清理。
- 侧边栏“本机”列出主目录、文件系统（Windows 下为各个盘）和已挂载的网络共享、移动硬盘，可逐级展开浏览本机文件。选中文件夹或文件后右键选择“创建备份任务…”，在弹窗中设置目标和模式；在空白处右键选择“备份当前文件夹…”。“在文件管理器中显示”也在右键菜单里。
- “备份任务”每个任务一张卡片，显示备份内容、目标、模式和上次运行结果。“立即备份”比较后直接备份，进度和结果显示在卡片里（“详情”查看完整结果和出错文件）；只有会删除 NAS 上文件时（完全一致模式）才先打开预览请你确认，比较出错时也会打开预览。卡片的 ⋯ 菜单里有“预览并备份…”“详情与运行记录”“编辑…”“删除任务…”。系统托盘菜单中的备份任务也是立即备份。
- 新建/编辑任务的对话框：模式用分段按钮切换，只显示当前模式的说明；排除规则收在“高级选项”里。保留原来的增量、完全一致和归档功能。左下角“设置”打开设置页：服务器（状态、登录、管理、编辑、网页管理）、本机索引（状态、索引目录、更新、编辑范围）和常规（关闭窗口时最小化到托盘、设置文件夹、清除最近搜索）。

复制沿用 fileindex 的现有策略：目录里的符号链接会跳过，任务完成时会显示服务器返回的跳过提示。上传和目录下载会保留符号链接。

第二阶段的预览和打开已实现：

- 双击图片、文本、PDF 或网页会打开原生预览，支持上一项、下一项；文本只读且可选择复制。图片支持适合窗口、原始大小，滚轮以指针为中心缩放（双击切换原始大小），放大后拖动平移，松手带惯性滑行、拖过边缘会回弹；未放大时左右甩动切换上一张、下一张。缩放和平移是同一个弹簧动画。
- 图片支持 JPEG、PNG、GIF（首帧）、WebP 和 BMP；JPEG 根据 EXIF 自动转正。预览限制 32 MiB 和 1600 万像素，超出时可用系统程序打开。
- 文本支持 UTF-8、UTF-16 和 BOM，常见源码、配置、日志、字幕也可预览；最多读取前 256 KiB，超出时提示打开完整内容。SVG 等按文本显示。
- PDF 和网页（HTML）在系统网页视图里预览：Linux 上是 WebKitGTK 自带的 PDF 阅读器，Windows 上是 WebView2；PDF 最多 32 MiB，网页最多 4 MiB。网页放在沙盒框架里，不运行脚本、不加载任何外部资源、不能跳转到其他地址，可切换查看源代码。没有网页视图时提示原因，可用系统程序打开。
- 音视频通过仅监听 `127.0.0.1` 的本机代理播放，支持 HTTP Range 拖动。客户端生成 `.m3u` 播放列表交给系统默认播放器，因此需要将 `.m3u` 关联到 VLC、mpv 等支持 HTTP 播放的程序；右键“下载后打开”可供不支持网络播放的程序使用。播放期间需要保持 FileSync 运行。
- Office 和其他文件通过本机代理下载到缓存，再用系统默认程序打开；需要本机安装对应的阅读器或 Office 软件。缓存按服务器、路径、文件大小和修改时间区分，未完整下载的内容不会替换已有缓存。预览工具栏和右键菜单也可选择“系统程序打开”。系统程序保存的修改留在本机缓存，不会自动上传，重新打开同一 NAS 版本会保留这些修改；要更新 NAS 文件请手动上传。
- 每个服务器下面都有原生“回收站”页面，支持筛选、多选恢复和确认后永久删除，自动响应实时事件。恢复同名文件时由服务端自动编号；只读目录中的项不能恢复或删除。永久删除进度进入任务面板。

代理 URL 使用独立随机凭据，不包含 NAS 登录会话；退出登录、更改服务器或关闭客户端会撤销链接并停止对应的流。

第三阶段的原生管理包括：

- 每个服务器下的“目录管理”支持添加索引目录、浏览服务器目录、编辑名称、只读状态和排除规则，以及按小时、每天或每周自动更新。时间按服务器时区执行。
- 可以启动增量更新、确认后完整校验、取消扫描，并查看最近 20 次扫描记录。扫描进度进入全局任务面板，通过实时事件更新；定期查询扫描记录以恢复遗漏的事件。
- 移除索引前会确认，不删除硬盘原文件，但会移除该目录的扫描和回收站记录。已有备份任务保留，需要自行重新设置被移除的目标目录。
- “查重”支持选择一个目录或全部目录、设置最小大小、分页查看内容相同的文件。本页可按修改时间保留最早或最新的副本，每组至少保留一份；只读副本不可删除。删除勾选的副本前会确认，文件进入回收站。
- “空间统计”显示总大小、文件数、文件夹数、类型、扩展名、修改年份和最大的 50 个文件。文件类型是环形图，指向扇区或图例时两边一起高亮；修改年份是带刻度的柱状图，指针或左右方向键逐年查看大小和文件数。文件夹占用可逐级展开，大文件和重复文件都可以预览或定位到所在目录。
- 统计读取索引；扫描和查重会读取 NAS 硬盘。文件变化后自动刷新统计和查重结果。以上功能复用现有服务端接口，不需要额外部署。

## 局域网发现

“服务器列表…”和添加服务器对话框会自动扫描同一局域网中的 fileindex 服务，显示名称、地址和已添加状态；点“选择”填入名称和地址，再保存并按原流程登录。扫描 5 秒，可重新发现；手动输入仍可使用。需要支持 `_fileindex._tcp` mDNS/DNS-SD 的新版服务端；Docker 服务端需使用 host 网络。跨子网、AP 隔离或组播被拦截时请手动添加，当前自动发现使用 IPv4。协议见 [DISCOVERY.md](../fileindex/DISCOVERY.md)。

## 服务器压缩

NAS 文件的右键菜单和选中后的“更多”提供“压缩到…”，搜索中的同一服务器、同一索引目录结果也可压缩。可设置包名、ZIP/tar.gz/tar.zst 格式、快速/标准/较小体积三级压缩，以及保留两份/覆盖/跳过；默认 ZIP、标准、保留两份。保存位置限同一服务器，可从只读目录读取后保存到其他可写目录。源文件保留，数据不经过客户端。

任务由服务器后台执行，传输记录显示进度、取消和最终位置；完成后可打开压缩包所在目录。关闭 FileSync 不取消压缩，重开传输记录可恢复服务器仍保留的任务，删除历史不会让已删除的记录重新出现。服务端重启不会自动续跑；记录丢失时提示无法确认结果。需要更新 fileindex 以提供 `/api/archive/compress`；旧服务端会提示更新。

## 压缩包实时浏览

本机或 NAS 页双击压缩包（右键也有“打开压缩包”）直接进入只读目录。复用列表、网格、排序、多选、面包屑、后退/前进和 Alt+↑；图片、文本、PDF、网页沿用现有预览。系统程序打开时只把目标文件下载到本机缓存，缓存身份包含压缩包路径、版本和包内路径。压缩包页面的“下载…”将选中项解压到本机；“解压到…”可选本机、这台服务器或其他服务器。**同一服务器解压由 fileindex 后台任务直接读取压缩包并写到目标目录，文件数据不经过客户端；同名项默认保留两份。** 解压到本机或其他服务器继续沿用同名询问、tar 完整性检查和 Relay。普通压缩包右键菜单也有“解压到…”，选同一服务器时不用先浏览压缩包即可提交任务；fileindex 网页的文件菜单和选中操作条也支持“解压到…”，可选择保留两份、覆盖或跳过。内容只读，不提供上传、新建、改名、移动或删除。

NAS 浏览需要更新 fileindex，使其包含三个已登录只读接口：

- `GET /api/archive/list?root=&path=&dir=` 返回 `items`、`version` 和 `sequential`；`progress=1` 返回读取进度 JSON 行，最后一行为 `end:true` 及结果或错误。客户端可以取消请求。
- `GET /api/archive/file?root=&path=&entry=&version=` 流式返回一个文件及其长度。`limit` 可请求预览前缀，最多 32 MiB + 1 字节。完整文件通过大小及解码校验后才释放末块。
- `GET /api/archive/export?root=&path=&entry=…&version=` 将所选文件和目录导出为标准 tar，与 backup/export 的 `X-Total-Size` 和 `X-Export-Complete` 协议一致。
- `POST /api/archive/extract` 接收 `root`、`path`、可选 `version`、`entries`、`dst_root`、`dst_dir` 和 `conflict`，返回 `{task:…}`。省略 `entries` 解压整个压缩包，省略 `dst_root` 使用源索引目录；`conflict` 为 `rename`（默认）、`overwrite` 或 `skip`。源可以只读，目标必须可写且目录已经存在。任务通过 `/api/tasks` 和 SSE 报告进度，可用 `/api/tasks/{id}/cancel` 取消。客户端断开不影响已提交任务；取消或失败保留已完整写好的文件，当前文件的临时输出会被清理。解压后更新索引，不删除原压缩包。

读取支持 ZIP（无 UTF-8 标记的名称按 GB18030 解码）、RAR4/5、7z、tar、tar.gz/tgz、tar.bz2、tar.xz、tar.zst，以及单独的 gz、bz2、xz、zst。全部使用纯 Go 库；浏览不会在磁盘解压或下载整个 NAS 压缩包。目录按文件路径、大小和纳秒修改时间缓存：LRU 最多 16 个包、估算元数据共 64 MiB。每包最多 100 万条目（元数据内存限制可能更早达到），并发解压最多 2 个，单文件最大 8 GiB、一次扫描/导出最大 32 GiB；解压量还受压缩比和解码字典内存上限约束。危险路径、规范化后重名和文件/目录冲突会拒绝；符号链接和硬链接只显示，目录解压跳过链接。

首次读取 tar 压缩流和单文件压缩流需要顺序扫描，界面显示读取量并可取消。打开 tar 内靠后的文件或固实 7z/RAR 成员也会较慢。加密包或加密成员只显示提示，第一阶段不输入密码；包内音视频下载后再打开；搜索不包含包内文件。多卷压缩包不支持。

`internal/archive/` 是客户端与 fileindex 的同源读取代码。两个仓库保持独立 Go 模块，通过 `scripts/sync-archive.sh [fileindex仓库路径]` 同步读取器、测试和样本；修改读取代码后两边都需运行测试。

## 功能

- **多个服务器**：在“设置 → 服务器列表…”中添加、编辑、删除 fileindex 服务器（名称 + 地址），登录或退出登录。只保存登录会话，不保存密码；会话过期时预览会提示重新登录。还有任务在用的服务器不能删除。
- **选择备份到的目录**：选择服务器 → 登录 → 选择 fileindex 的索引目录 → 逐级进入子目录，也可以新建文件夹。
- **三种模式**
  - 增量备份：上传新增和修改过的文件，NAS 上多出来的文件保留不动。
  - 完全一致：在增量备份的基础上，把本机没有的文件移到 fileindex 的回收站（默认保留 30 天）。
  - tar 归档：把整个源目录打包成一个归档文件保存到 NAS，每次生成一个新文件（如 `xiaomai-20261010-160500.tar.gz`），不与 NAS 上已有的内容比较。可选 gzip（默认，多核并行压缩）、不压缩或 zstd。请求末尾附带字节数，NAS 核对完整后才以正式文件名保存。
- **同名文件夹**：备份一个文件夹时，默认在目标中创建与它同名的文件夹（归档模式下是归档里的顶层文件夹）；取消勾选则只备份文件夹里的内容。
- **备份选中的多项**：同时选中多个文件或文件夹（或单个文件）时，它们直接放进目标目录；同一目录下没选中的项不会上传，完全一致模式也不会删除 NAS 上它们以外的文件。
- **先预览再执行**：先列出要新增、更新、删除、跳过的文件，确认后再开始。
- **排除规则**：glob 语法，例如 `*.tmp`、`node_modules`、`cache/`、`/build/out`。

## 本机文件检索

在“本机”页面底部状态栏的“索引”菜单中选择“索引范围…”设置本地目录和排除规则，再选择“更新索引”（还没有索引时，搜索页也有“建立索引”按钮）。默认范围是主目录，默认排除 `.cache/`；其他本地磁盘可以添加绝对路径。扫描在后台运行，可取消；首次扫描会逐步发布结果，扫描期间也能搜索。

- 按文件名搜索，空格分隔的词须同时匹配，忽略大小写；结果在统一的搜索页里（见上文），本机结果来自这份索引。
- 选中本机的搜索结果可创建备份任务。来自不同目录的结果按来源目录分别打开设置窗口；保存后继续设置下一个，取消会结束剩余设置。
- 索引只读取文件名和元数据，不读取文件内容。扫描去除重叠范围，跳过识别出的网络挂载、系统虚拟目录和特殊文件，符号链接不会递归扫描。

本机索引完全由手动扫描更新，没有文件监听、定时扫描或启动扫描。“刷新”重新查询当前索引；文件新增、修改、移动或删除后，需要在“索引”菜单中选择“更新索引”。不可读目录保留已有记录并显示提示；取消重扫时，尚未完成的索引范围保留旧记录；取消首次扫描保留已建立的部分。

第二阶段已实现快照持久化和手动增量更新：

- 启动只在后台加载已有快照，不扫描索引目录。加载后可以直接搜索离线目录中的旧记录；打开已移动或删除的文件会提示手动更新。
- “更新索引”核对目录修改时间。未变化的小目录复用文件名列表，仍逐项核对已有文件的大小、修改时间、类型和隐藏属性；发生变化的目录重新枚举，大目录分批读取以限制临时内存。“全部重建”重新枚举全部目录。
- 目录时间比对不能识别其他程序强行恢复目录时间后新增的未知文件，也不能提供整个文件系统在同一时刻的快照；遇到这类情况请使用“全部重建”。更新在内存中重建不可变结果版本，以保持分页一致。
- 完成手动扫描后自动保存带格式版本、索引范围校验和 SHA-256 校验的二进制快照，通过临时文件、同步写入和原子替换保存。损坏、旧格式或配置不匹配的快照不会被发布，界面会提示手动重建。保存失败时当前索引仍可搜索。
- 取消扫描或保存会保留磁盘上的已有快照；本次尚未保存的数据只在当前进程中可用。不可读范围保留旧记录，相关提示也随快照保存，重启后仍会显示。改变索引范围或排除规则后旧缓存失效，需要手动重新建立。

快照默认位于 `~/.cache/filesync/local-index.bin`（遵循 `XDG_CACHE_HOME`），Windows 位于 `%LocalAppData%\filesync\local-index.bin`；索引范围和排除规则继续保存在设置文件中。状态栏显示加载、核对目录、保存进度和上次更新时间。扫描期间旧、新索引可能同时存在，搜索结果也保留其所属版本，实际进程峰值内存会高于索引本身。

已有快照在启动时流式校验，保留目录表和数据块位置；搜索和目录统计按需读取二进制文件的数据块，不把全部文件记录常驻内存。搜索命中结果按每项一位的位图保存，分页按全部结果排序；深分页仍需要保存更多排序候选。搜索速度受磁盘和系统文件缓存影响。扫描和更新暂时仍会构建内存索引，保存完成后切回按块读取，因此更新期间峰值内存可能较高。兼容已有快照，无需重建索引。

百万项模拟数据的测量命令：

```sh
go test ./localindex -run '^$' -bench BenchmarkMillion -benchmem
```

## 传输方式

不经过 SMB，而是直接和 fileindex 通信：

- NAS 在本地一次性列出目标目录（2 万个文件约 0.1 秒）；
- 要传的目录、文件和符号链接作为**一条标准 tar 流**，在**一个连接、一个请求**中连续发送，磁盘可以顺序写入，小文件也不用逐个往返；
- NAS 边收边解开成普通文件，每写好一个就回一条确认：进度显示的是 NAS 上真正写好的文件，连接中断时也能准确知道哪些已经写好，下次备份会接着传；
- 保留修改时间、可执行权限和**符号链接**；文件属主沿用 fileindex 的设置（Unraid 上为 nobody:users，与 SMB 写入的一致）；
- 文件写好后，服务端异步更新索引，并通过实时事件通知客户端刷新。

需要 NAS 上的 fileindex 包含 `/api/backup/manifest`、`/api/backup/tar` 和 `/api/backup/file` 接口（`/api/backup/file` 需要支持 `X-Backup-Size` 结尾标记）。

目录下载还需要 `GET /api/backup/export?root=索引目录ID&path=相对路径`（`path` 可重复）；返回标准 tar 流，`X-Total-Size` 是索引中的估计字节数，`X-Export-Complete: 1` HTTP trailer 表示导出完整结束。客户端也会检查 tar 的结束块。

## 安全措施

- 完全一致模式下，如果源目录为空而 NAS 上有文件，拒绝执行（防止源目录未挂载时清空备份）。
- 要删除 NAS 上一半以上的文件时，会再次弹窗确认。
- 删除的文件进入 fileindex 回收站，可以恢复；含有被排除文件的目录会保留。
- NAS 上每个文件先写入临时文件，完整后再改名，不会留下写了一半的文件；传输中被修改而读不完整的文件会被丢弃，下次重传。
- NAS 拒绝写到索引目录之外，包括经由符号链接。
- NAS 上无法读取的目录，其中的内容不会被删除。
- 设备、管道等特殊文件会被跳过。

## 开发

需要 Go 1.27.3 或更高版本（MyGo v0.6.4 的要求）。Linux 上运行还需要 GTK 3。

```sh
go run .                 # 运行
go test ./...            # 测试（界面测试不需要窗口，用 fileindex/fitest 模拟服务器）
go tool mygo dev         # 开发模式，修改代码后自动重新加载
go tool mygo build       # 打包
GOOS=windows go build -o filesync.exe .   # 在 Linux 上交叉编译 Windows 版本
```

跨工程的断点续传测试可以启动本地真实服务端，在临时目录中验证中断、重新连接、源文件变化以及 SHA-256 完整性，不操作现有 NAS：

```sh
go -C ../fileindex build -o /tmp/fileindex-resume ./cmd/fileindex
FILESYNC_RESUME_SERVER_BINARY=/tmp/fileindex-resume go test ./fileindex -run TestDownloadResumeRealServer -v
```

对真实的 fileindex 测速：

```sh
FILESYNC_E2E_ADDR=192.168.0.235:8090 FILESYNC_E2E_TOKEN=会话 FILESYNC_E2E_SRC=本机目录 go test -run E2E -v ./fileindex
```

设置和日志保存在 `~/.config/filesync/`（Windows 上是 `%AppData%\filesync\`），设置文件只有本人可读。
