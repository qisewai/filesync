# FileSync 文件备份

手动运行的目录备份工具，支持 Linux 和 Windows，界面使用 [MyGo](https://github.com/egoist/mygo) 的 Native UI 编写（纯 Go，不需要 cgo，也不需要 WebView）。

## 功能

- **两种模式**
  - 增量备份：复制新增和修改过的文件，目标中多出来的文件保留不动。
  - 完全一致：在增量备份的基础上，再删除目标中源没有的文件。
- **先预览再执行**：先列出要新增、更新、删除、跳过的文件，确认后再开始。
- **排除规则**：glob 语法，例如 `*.tmp`、`node_modules`、`cache/`、`/build/out`。
- **网络目录**：源和目标可以是任何能访问的目录，SMB、FTP 等可以先在系统中挂载好。
  在 KDE 下，“浏览…”打开的是 KDE 文件对话框，可以直接选择 Dolphin 中收藏的网络位置及其子目录。
  这类目录会保存成 `smb://…` 地址，每次备份前通过 kio-fuse 重新打开，所以重新登录后依然有效。
  不过 kio-fuse 比较慢，目录很大时建议用 `mount.cifs` 或 Smb4K 挂载。

## 安全措施

- 完全一致模式下，如果源目录为空而目标有文件，拒绝执行（防止共享未挂载时清空备份）。
- 要删除目标中一半以上的文件时，会再次弹窗确认。
- 每个文件先写入临时文件，完成后再改名为正式文件，中断时不会留下写了一半的文件。残留的临时文件会在下次运行时清理。
- 源中无法读取的目录，目标中对应的内容不会被删除。
- 源目录和目标目录不能相同，也不能一个在另一个里面。
- 如果目标不区分大小写（如 Windows、SMB 共享），会检测只有大小写不同的文件名和 Windows 不允许的文件名，跳过这些文件并给出提示。
- 符号链接和特殊文件会被跳过。
- 修改时间相差不超过“时间容差”（默认 2 秒）且大小相同的文件视为没有变化。FTP 挂载可以把容差调大。

## 开发

需要 Go 1.27.1 或更高版本。Linux 上运行还需要 GTK 3。

```sh
go run .                 # 运行
go test ./...            # 测试（界面测试不需要窗口）
go tool mygo dev         # 开发模式，修改代码后自动重新加载
go tool mygo build       # 打包
GOOS=windows go build -o filesync.exe .   # 在 Linux 上交叉编译 Windows 版本
```

设置和日志保存在 `~/.config/filesync/`（Windows 上是 `%AppData%\filesync\`）。

## 代码结构

```
engine/   同步引擎：扫描、比较、生成计划、执行，不依赖界面
config/   任务和运行记录的读写
places/   smb:// 等网络地址和 kio-fuse 本地路径之间的转换
app.go    任务列表、任务详情、编辑页面
job.go    预览、执行进度、结果页面
runlog.go 每次运行的日志文件
main.go   窗口和系统接口（目录选择对话框、打开文件、防止休眠）
```
